# Demo Script

This script is designed for a short live demo or screen recording.

## Setup Line

> This is OpenWhip: a tiny interaction layer that turns waiting for AI into visible feedback.

## Demo Flow

1. Start an AI task that appears to be thinking or generating.
2. Press `Option + A`.
   - Say: "First, wake it up."
   - Visual: red whip.
   - Phrase: "第一鞭，先醒醒，别让我干等。"
3. Press `Option + S`.
   - Say: "Now a light nudge."
   - Visual: orange whip.
   - Phrase: "快一点，别让我在这儿干等。"
4. Press `Option + D`.
   - Say: "Raise the tempo."
   - Visual: yellow whip.
   - Phrase: "再快一点，节奏拉起来。"
5. Press `Option + F`.
   - Say: "If it feels stuck, use the blue one."
   - Visual: blue whip.
   - Phrase: "别卡住，往前冲。"
6. Press `Option + G`.
   - Say: "Back to work mode."
   - Visual: green whip.
   - Phrase: "干活干活，别偷懒。"
7. Press `Option + H`.
   - Say: "And finally, review and close."
   - Visual: purple whip.
   - Phrase: "最后检查一遍，收工别漏东西。"

## Closing Line

> OpenWhip does not make AI faster. It makes waiting feel designed.

## Safety Note

OpenWhip is only a visual feedback layer. It does not interrupt tasks, send terminal commands, or access private content.
